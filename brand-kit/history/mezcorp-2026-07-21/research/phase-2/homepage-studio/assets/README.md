`logos/claude.svg`, `logos/openai.svg`, `logos/notion.svg`, and `logos/gemini.svg` are local copies of the existing logo sources used by Mez creative and the AI OS website variants. The synthesis renders them as alpha masks in one neutral grey. Their original brand colours are not used.

The OpenAI mark represents both ChatGPT and Codex where the current public products share the OpenAI parent mark. This is a research treatment, not a final product-logo decision.
