# 00 · Brand architecture

## The three tiers

```
Mez Studios        the parent company. Off-white + near-black + the wings.
  └── Mez Systems  the digital-products holdco. Off-white + near-black + the wings.
        ├── AI OS   AI Operating System      core = MZ-G13
        ├── Aurora  Auto Ads System          core = MZ-G20
        ├── Prism   Analytics Pack           core = MZ-G06
        └── Forge   Claude Code OS           core = MZ-G15
```

Mez Systems is endorsed by Mez Studios. In formal lockups it reads "A Mez Studios company".

## What each tier owns

Since the surface V1 lock, the whole system is monochrome (near-black `#0D0D0D` on off-white `#F8F8F8`); the **tier is encoded by radius**, not by a separate colour. The product gradient is the only colour, and it belongs to products.

| Tier | Colour | Mark | Corner radius |
|------|--------|------|---------------|
| Mez Studios (parent) | Near-black `#0D0D0D` on off-white | Wings, mono | Nearly square (small radius) |
| Mez Systems (holdco) | Near-black `#0D0D0D` on off-white | Wings | Medium radius |
| Product (e.g. AI OS) | Its own gradient core | Wings on the gradient | Fully round (pill) |

## Radius is scale

The single most ownable rule in the system: **roundness falls as the entity grows.**

- A **product** is small, fast, consumer-facing, so it is a **fully round pill**.
- The **holdco** is bigger, so it eases off to a **medium radius**.
- The **parent** is the whole company, so it is **nearly square**.

This shows up everywhere: product pills, logo lockups, card corners. When in doubt about how round something should be, ask what tier it represents.

Reference board in Figma: "Pill-led · radius is scale" (Drafts page, node `119:31`) and the UI pills board.

## Why the holdco is not a gradient

Products are colourful because they compete for attention on landing pages and in feeds. If the holdco were also a gradient it would just look like "all the products at once" and stop reading as the parent. So the holdco stays monochrome (a single, calm near-black `#0D0D0D`) and lets the products carry the colour. This keeps the parent legible standing next to its own products.
