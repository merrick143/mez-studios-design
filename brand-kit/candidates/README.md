# Candidate workspace contract

Candidates are research objects, never canonical assignments.

The local workbench accepts a square PNG, JPEG or WebP of at least 512px. It generates:

- an exact 1600px static twin;
- deterministic four-anchor parametric data;
- animated sphere, disc, card field, pill and Wings expressions;
- a candidate metadata record;
- a separate select, edit or reject decision record.

Generated files live under `brand-kit/workspace/candidates/`, which is ignored by Git. Candidate generation never edits the imported source pack, the Mezcorp canonical pack or a portable release.

Promotion happens only after a human decision and a separate canonical update.
