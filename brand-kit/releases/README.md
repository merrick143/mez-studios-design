# Releases

`0.1.0-alpha.1` is the active canonical identity snapshot. It is self-contained and hash-verified, but it is deliberately not the foundation-complete production release.

It contains:

- the literal five-product registry and approved assignments;
- all 43 exact PNG source IDs, 33 active cores and ten compatibility aliases;
- all exact static twins, canonical Wings and the shared Living Core renderer;
- the Deep Mineral finish, nine approved decisions and six machine-readable schemas;
- a standard-library verifier and complete artifact manifest.

Run `python3 brand-kit/releases/0.1.0-alpha.1/verify.py` to validate it without access to the rest of the repository.

The prior `2026.07.20-living-core` export is useful evidence, but it predates the approved Geist-display and tuned-Inter split and therefore cannot be promoted unchanged.

A future production-ready release can be promoted only when:

1. its source commit and decision IDs are recorded;
2. every file is hashed in its manifest;
3. the Living Core palette conflict is closed;
4. Context Engine status is honest;
5. foundations and product-expression rules are approved;
6. clean-copy validation passes;
7. one real consumer successfully ingests it.

The migration alpha satisfies the identity-kernel and authority-transfer gates only. Foundations, product expressions and consumer certification remain explicit post-cutover work.
