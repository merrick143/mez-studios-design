# Mez Systems Wings and mark contract

`wings-mark-01` is canonical `1.0.0` through `H-EXP-03-WINGS-MARK-PROOF` and `DEC-WINGS-MARK-EXPRESSION-001`. It preserves the exact two-path Wings and defines one restrained hierarchy: charcoal/white Mez Systems lockup, standalone compact mark, white product-core mark, and rare gradient-mask expression.

It explicitly parks icon, roundel, monoline, keyline, emboss, co-branding and endorsement work for later channel or identity gates.
