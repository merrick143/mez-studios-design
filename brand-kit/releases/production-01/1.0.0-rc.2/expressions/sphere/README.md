# Mez Systems sphere contract

`sphere-contract-01` is the canonical `1.0.0` rare focal state of the canonical product disc. It adds only the approved renderer-owned sphere depth and bounded scale/crop behaviour.

The contract does not change the disc, gradients, renderer, Deep Mineral finish, product assignments, Wings, foundations, homepage composition, Figma, or any production consumer. Its bounded production authority is backed by `H-EXP-02-SPHERE-PROOF` and `DEC-SPHERE-EXPRESSION-001`.

Build with `python3 brand-kit/expressions/sphere/build_sphere_contract.py` and verify with `python3 brand-kit/expressions/sphere/verify_sphere_contract.py`.
