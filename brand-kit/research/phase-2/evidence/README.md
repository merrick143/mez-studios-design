# Deep-source evidence

Status: research evidence, not brand truth
Cycle: Phase 2, H1-approved panel
Capture date: 20 July 2026

This directory contains one deep study for each approved source: Notion, Linear, Stripe, ElevenLabs, and Ramp.

Each study must separate observed evidence from interpretation, identify category conventions, derive transferable principles, exclude source signatures, state limitations, and label every Mez hypothesis as unapproved.

Evidence IDs use the source prefix and a stable sequence, for example `NOTION-E-001`. A page URL supports an observation. It does not prove why a design works, private product behaviour, performance, or internal design intent.

The files are inputs to `../COMPARATIVE-SYNTHESIS.md`. They never become canonical tokens or rules directly.
