# TR-6 original direction review

Status: human review candidate, no production authority

This instrument presents three original Mez directions across the same eight surfaces: website, product UI, product family, advertisement, email, report or deck, small-format identity, and motion storyboard.

## Run

From the Mez Systems pack root:

```bash
python3 -m http.server 8908
```

Open `http://127.0.0.1:8908/research/phase-2/directions/`.

## Review

For each route choose contender, useful donor, or reject. Select up to four behaviours that should survive even when a route loses. Notes are optional. Export the final JSON record after reviewing all three routes.

The routes are research prototypes. A contender is permission to refine, not permission to migrate production assets, tokens, components, Figma, or consumer repositories.
