CANONICAL BOUNDARIES

Calm enough to disappear.

  • Use 120ms for feedback, 180ms for state, 240ms for spatial changes and no more than 360ms for section entry.
  • Do not autoplay carousels, hijack scroll, pin long stories, add parallax decoration or animate every section.
  • One approved Living Core may move internally; Wings, labels, layout and controls stay fixed.
  • Tabs, accordions, carousels and processors animate only because the user changes their state.
  • The actual global navigation will be built separately under TASK-CMP-01-GLOBAL-NAVIGATION from the existing explore-menu research evidence.
  • 21st.dev may supply later implementation candidates, but the candidate must conform to this grammar—not define it.
  • DEC-WEBSITE-MOTION-SYSTEM-001 closes H-EXP-07-CHANNEL-MOTION-PROOF for this bounded seven-behaviour grammar.
