# Mez Systems channel packs

Channel packs extend the canonical engine into repeatable outputs. Every pack inherits foundations and expressions; it cannot create conflicting brand values.

## Registry

- [`paid-social/`](paid-social/) contains one `CRAFT_APPROVED` format: `Static: Price-Anchored Product Proof` version 1.0.0.

The paid-social channel itself remains uncertified. A pack may contain a craft-approved format without completing every family, ratio, production route, public-use gate or outcome proof required for channel certification.

Use `registry.json` for machine routing and each pack's `manifest.json` for the exact authority boundary.
