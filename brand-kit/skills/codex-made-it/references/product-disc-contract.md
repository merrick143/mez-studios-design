# Mez Living Core expression contract

## Core representations

Every product core has:

1. a source PNG that owns extraction and colour truth;
2. an exact static WebP twin for fixed delivery and fallback;
3. a parametric runtime core for approved animation.

The runtime approximation never replaces source authority.

## Shape grammar

### Disc

- Use a perfect circular mask with a hard edge.
- Use it as the canonical compact product object and default card object.
- Place the canonical white Wings directly inside the gradient.
- Do not add an inset tile, halo, glow cloud, or floating decoration.

### Sphere

- Use the same palette, motion, and Wings treatment as the disc.
- Add only approved spherical shading.
- Reserve it for a hero, launch frame, or one focal product.

### Rounded rectangle

- Use the same field under an approved rounded-rectangle mask.
- Fill a trading-card field or pill edge to edge.
- Keep copy, price, status, CTA, border, and shadow static.

### Wings mask

- Use canonical two-path Wings geometry as the shader mask.
- Reserve gradient Wings for an identity or motion study.
- Keep ordinary product marks as white Wings inside the core.

## Collection rules

- Give equal products equal geometry and alignment.
- Differentiate products with approved core and copy, not arbitrary chassis changes.
- Do not use jagged card sizes or misaligned catalogues.
- Allow several animated cores only on a bounded calibration board.
- Default production to one animated focal core per viewport.
- Keep bundles, upsells, repeated catalogues, and dense UI static.

## Channel defaults

- Website hero: one focal animated core after consumer approval.
- Product cards, catalogues, checkout, bundles, and upsells: exact static twins by default.
- Email, still ads, social stills, OG, documents, presentations, print, PDF, and icons: static only.
- Video: one focal core may animate; structural overlays and final frame remain static.

## Motion

- Use slow, continuous motion with no visible loop.
- Do not spin, pulse, breathe, bounce, spring, or scroll-reveal the core.
- Let hover change field speed only.
- Keep geometry, Wings, and structural overlays static.
- Pause hidden and offscreen work.
- Show the exact static twin for reduced motion or runtime failure.

## Promotion gate

Promote a candidate only after:

1. source-versus-runtime comparison;
2. human select, edit, or reject decision;
3. assignment recorded in governance;
4. canonical data and release data generated atomically;
5. deterministic and runtime validators pass.
