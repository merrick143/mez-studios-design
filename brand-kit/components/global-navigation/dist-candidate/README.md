# Mez Systems global navigation

Status: review candidate `global-navigation-01-r04`. No production authority until `H-CMP-01-GLOBAL-NAVIGATION-PROOF` closes.

This candidate promotes one refined `Registry` family from the five-direction `explore-menu/` research. It removes numbered-system styling, parallel production variants, five simultaneous live cores and horizontal mobile discovery.

Load the foundation CSS, `mez-global-navigation.css`, and `mez-global-navigation.js`, then use:

```html
<mez-global-navigation
  selected="aios"
  home-href="/"
  systems-href="/systems/"
  about-href="/about/"
></mez-global-navigation>
```

The default charcoal surface is the primary family. `surface="light"` is the one bounded option for a contained dark host section. Product activation emits `mez-product-navigate`; the consumer supplies real destinations and decides what navigation occurs.

The compact Explore control includes a layered stack of all five exact static product circles, making the family visible before disclosure. The disclosure uses a calm eased shell expansion and a restrained five-item entrance sequence; closing remains direct and interruptible. It supports Escape, outside click, focus restoration, Tab containment, arrow-key product movement, Home and End without printing keyboard instructions into the menu. Desktop presents five equal products and ends cleanly after the registry. Mobile recomposes into a vertical sheet. All five Deep Mineral spheres mount automatically while the registry is expanded; hover retains the renderer's approved speed response. Reduced-motion, forced-static and WebGL-failure paths retain five exact static circular twins.

This five-live-sphere allocation is a candidate exception to the canonical default of one animated focal core per viewport. It applies only to this bounded expanded navigation if Olli approves Round 02; it does not silently rewrite the global Website Motion decision.

Fixtures in `fixtures/` show dependency-free HTML and a thin React event adapter. They do not own routes or product data.
