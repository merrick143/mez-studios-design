What to do

  1. Pick any verdict — all three exercise the same write path.
  2. Leave the suggested decision id, or change it. Approving requires one; the other verdicts do not.
  3. Write a note. It is required, and it lands in both the gate record and the register.
  4. Click Record decision & write to repo.
  5. Watch this item leave the Review queue on its own — the registry regenerates itself.
  6. Check git diff to see exactly what changed.
