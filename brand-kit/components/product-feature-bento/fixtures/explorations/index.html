The content is identical in all ten. Eight building blocks of a business; four of them named exactly as the registry names the function each system serves, so those mappings are read rather than asserted; four with no system, carrying no claim and no disc; and the AI OS as the layer. The only variable is the composition.

The defect these are fixing. The first version said "the layer they run on" and then drew the AI OS as one big cell beside eight small ones. The composition did not make the claim the copy made. Numbers 1, 3, 6, 8 and 10 each answer that differently.

One contract decision was needed to build number 3. The rule is one colour event, not one material cell. A single band running behind every cell and showing through an aperture in each is one object seen through many windows, so it spends the same single event. Declaring a layer and a material cell is now the violation, and the component rejects it.

Number 9 I expect to lose, and it is here to be judged on the render rather than on my say-so: a ring around a centred core is GH-S03's concentric orbit two sections earlier. Number 7 is binary today because the real weighting of how systematised each block is can only come from you.
