Favicons

SVG

Favicons are per-site and already static — the shader can't run in a browser tab icon. What each property ships today:

This site — /favicon.svg: the wings filled with MZ-G13 flattened to a linear ramp. The canonical starting point: new sites copy this file and swap the ramp for their own product's gradient stops rather than inventing a new mark.

mez.systems — three files in the landing repo's public/. Only the first is what you see in a browser tab.

Worth knowing: favicon.ico is declared first with sizes="any", so that is the one browsers actually show in the tab — dark wings on white. favicon.png is its inverse and carries no media="(prefers-color-scheme: dark)", so it is not a dark-mode pair; it is just inconsistent. If a browser ever prefers it, the tab icon flips appearance.

mez.studio — favicon.ico (6 sizes) + apple-touch-icon.png (180). The studio property, on the same dark-wings-on-white treatment as mez.systems.

mezcorp.co — /brand/icon-light.svg + a 6-size favicon.ico. The agency mark, separate from the Mez Systems product identity by design.

Making a new graphic

  1. Pick a canvas and open it full size — every card's Open canvas button.
  2. Retitle it from the URL: the canvases are templates driven by query params (below).
  3. Capture at 100% zoom — browser devtools "capture node screenshot" on the .canvas element gives an exact-pixel PNG.
